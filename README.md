# FedlexQA

Multilingual question answering over Swiss federal law, with article-level citations and
claim verification. *(Work in progress. Live demo, results table and architecture diagram coming.)*

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```
